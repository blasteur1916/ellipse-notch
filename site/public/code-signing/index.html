Release and signing policy

Updated: 23 November 2026

Ellipse's Windows installer is not signed with a code-signing certificate yet, so Windows SmartScreen may warn about it the first time. Here is how each release is built, and how you can check what you install.

How releases are built

The Windows installer of each release (Ellipse-Setup-x64.exe) is published on GitHub Releases. Every installer is built by GitHub Actions from the tagged commit of the public repository, blasteur1916/ellipse-notch. Nothing built elsewhere is published.

How to check what you install

Each release carries Ellipse-Setup-x64.exe.sha256, the SHA-256 of its installer. In PowerShell, Get-FileHash Ellipse-Setup-x64.exe must print the same value.

Team

Committer, reviewer and approver: blasteur1916. Changes from other people come as pull requests, reviewed before they are merged.

Privacy

Ellipse has no account, no advertising and no telemetry, and connects to no Internet server. The full policy is on the privacy page.
